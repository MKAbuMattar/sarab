Animated wallpapers that rest when you work.

Sarab plays videos, GIFs, web pages and pictures behind your desktop icons, on one display or many. When an app covers the screen, the laptop runs on battery or the PC locks, the wallpaper freezes on its last frame, so it stays light on old PCs.

What it does

Everything a live wallpaper needs, and the good manners to step aside.

Rests when you work

A window covering a display, battery, energy saver, a locked screen, the screensaver, remote desktop or a busy CPU: the wallpaper freezes in place, and the window says why.

Every display

One wallpaper on all displays, a different one on each, or one stretched across them. Displays playing the same video stay on the same frame.

Your wallpapers

Videos, GIFs, pictures, web pages, web addresses and YouTube links. Programs can run behind the icons too, and rest with the rest.

Brings your library with it

Web, video and application wallpapers from Wallpaper Engine import with their settings. Sarab packages are plain zip files you can export and share.

Feels native

Light and dark, Acrylic or Mica, a library with categories, tags, search and thumbnails, and menus that look like the rest of Windows 11.

Changes with you

A new wallpaper every few minutes, in order or at random, through one category. A screensaver of your own, and mouse input for interactive pages.

Drive it from the command line

Every action is a sarab command, so scripts and hotkey tools can drive it. The installer puts it on your PATH.

  • sarab set <file, folder or URL> [--display N]
  • sarab pause, play, next, volume 30
  • sarab screenshot C:\shots\desk.png
  • sarab status --json for scripts
> sarab set C:\Wallpapers\dunes.mp4
> sarab status
Sarab 0.0.9 (pid 7428)
Display 1  1920x1080  dunes (video)  Playing
Display 2  1920x1080  dunes (video)  Resting: on battery

Install

  1. Run the installer. It installs for your user only, asks for a language, and fetches the WebView2 runtime if the PC lacks it.
  2. SmartScreen may warn about an unknown publisher, because the installer is not code-signed yet. Choose More info, then Run anyway.
  3. Updates are checked every few hours and installed only when you choose Update now, after their signature is checked.
